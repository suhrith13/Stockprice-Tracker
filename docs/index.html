Daily Prediction Track Record

Every weekday a model predicts each stock's closing price before the market opens. After the close the real price is recorded and compared. Results are measured against a naive guess ("today's close = yesterday's close"), which the model must beat to show any skill.

How you can check this isn't faked
  • Every prediction is stored with the exact time it was made, which is before the market opens.
  • Each row carries a SHA-256 fingerprint of itself plus the row before it. Changing any past prediction breaks every fingerprint after it. Your browser just re-checked all of them.
  • The log lives in a public GitHub repository, and GitHub's commit history independently shows when each prediction was published.
  • Actual closing prices can be checked against any public market data source.
